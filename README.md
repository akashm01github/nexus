# Nexus Pathology Lab

A responsive website for **Nexus Pathology Lab**, built with React and CSS.

**Live demo:** https://nexus-pathology.netlify.app/

---

## Overview

Nexus Pathology Lab is a front-end web application that presents the lab's services, information, and contact details in a clean, mobile-friendly interface. It is built with React (Vite) and styled with plain CSS.

## Features

- Responsive layout for mobile, tablet, and desktop
- Component-based React architecture
- Clean, custom CSS styling
- Fast development and build with Vite
- Deployed on Netlify

## Getting Started

### Prerequisites

- Node.js 18 or later
- npm (or yarn / pnpm)

---

### Build for production

```bash
npm run build
npm run preview
```
